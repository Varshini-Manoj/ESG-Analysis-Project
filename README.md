# 🌱 ESG Data Analysis Project

## 📌 Project Overview

This project focuses on analyzing Environmental, Social, and Governance (ESG) data to identify sustainability trends, compare industry performance, and understand the relationship between business performance and environmental impact.

The project demonstrates an end-to-end data analytics workflow using **Python, Excel, SQL, and Power BI**.

---

## 🎯 Project Objectives

* Analyze ESG performance across different industries.
* Identify companies with high and low environmental impact.
* Analyze carbon emissions and emissions intensity.
* Study the relationship between revenue and ESG performance.
* Clean and transform raw ESG data.
* Perform data analysis using SQL.
* Build an interactive Power BI dashboard.
* Generate meaningful business and sustainability insights.

---

## 📊 Dataset

* **Rows:** 11,001
* **Columns:** 16
* **Domain:** Environmental, Social & Governance (ESG)

The dataset contains information related to company performance, industry classification, revenue, ESG metrics, carbon emissions, and other sustainability-related indicators.

## 🔄 Project Workflow

### 1. Data Collection

Collected the ESG dataset containing company-level sustainability and business performance information.

### 2. Data Cleaning – Python

Python was used to:

* Identify missing values.
* Clean and preprocess the dataset.
* Calculate/fill missing growth-related values.
* Perform data transformations.
* Prepare the dataset for further analysis.

### 3. Data Validation – Excel

Excel was used to:

* Validate the cleaned dataset.
* Check missing and inconsistent values.
* Perform additional calculations and verification.

### 4. SQL Analysis

The cleaned dataset was imported into **SQL Server** for analysis.

SQL was used to perform:

* Aggregations
* Filtering
* GROUP BY analysis
* Industry-level comparisons
* Ranking
* KPI calculations
* Business and ESG performance analysis

### 5. Power BI Dashboard

Power BI was used to create an interactive ESG dashboard with:

* KPI cards
* Industry analysis
* Revenue analysis
* Carbon emissions analysis
* ESG performance analysis
* Emissions intensity
* Interactive filters and slicers
